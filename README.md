# Foresight in EU Impact Assessments: data bundle

Research data bundle for a study of strategic foresight use in EU-level
impact assessments (De Vito et al., UWE Bristol). Produced by the pipeline
at https://github.com/monkeymoves/eu-ia-foresight-pipeline, which documents
the full method.

**Start here: [the review page](out/review.html)** - every located
"foresight" mention across 162 Commission impact assessments (2022 onwards),
shown in context with links to the exact page of the source PDF.

Contents: `pdfs/` (source documents), `md/` (page-marked extracted text),
`docx/` (Word conversions), `out/` (dataset spreadsheet and review page),
`manifest.json` / `mentions.json` / `ai_drafts.json` (machine-readable
layers).

The PDF documents are European Commission documents obtained from the
[Register of Commission Documents](https://ec.europa.eu/transparency/documents-register/)
and are redistributed here under the Commission's
[reuse policy](https://commission.europa.eu/legal-notice_en) (CC BY 4.0);
they remain © European Union. Everything else in this repository is
released under CC BY 4.0.
